TECHNICAL DETAILS
================================================================================

Root Causes of Semaphore Leak:
  1. QThread objects created as local variables
  2. No closeEvent() to handle app shutdown
  3. Threads not being joined on exit
  4. Missing finally blocks for cleanup
  5. No thread lifecycle tracking

Solutions Applied:
  1. Keep persistent references via active_threads list
  2. Implement closeEvent() for proper shutdown
  3. Join threads with timeout before exit
  4. Add finally blocks to ensure completion
  5. Track threads from creation to cleanup

Impact:
  ✓ No more semaphore warnings
  ✓ Clean thread shutdown
  ✓ Proper resource release
  ✓ Production-ready code
  ✓ Backward compatible
