# Hebbian Amplification Jet Lag Mitigation App

This app simulates the effects of Hebbian amplification to mitigate jet lag, using deep brain stimulation as the representational energy transfer mechanism and congruential prime repair for neuronal pruning. Built with Streamlit for interactive exploration.

## Features
- Simulate Hebbian learning and amplification
- Model deep brain stimulation as energy transfer
- Apply congruential prime repair for neuronal pruning
- Visualize and analyze the impact on jet lag recovery

## Usage
1. Install requirements: `pip install -r requirements.txt`
2. Run the app: `streamlit run app/main.py`

## Scientific Background
- **Hebbian Amplification**: Strengthening of synaptic connections based on activity.
- **Deep Brain Stimulation**: Modeled as energy transfer to neural circuits.
- **Congruential Prime Repair**: Mathematical pruning of neurons to optimize recovery.
